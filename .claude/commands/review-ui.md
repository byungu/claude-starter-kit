1. 사용성 및 사용자 흐름 (Usability & User Flow): 사용자가 목표를 달성하는 과정이 직관적이고 매끄러운가? 병목 현상(Friction)은 없는가?

3. 인지적 부하 (Cognitive Load): 한 화면에 너무 많은 정보나 선택지가 있어 사용자를 피곤하게 만들지는 않는가?

5. 접근성 (Accessibility): 색상 대비나 글자 크기 등이 다양한 환경의 사용자를 배려하고 있는가?
